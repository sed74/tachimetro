# Content Rating Questionnaire (IARC) — bozza risposte per Play Console

Sezione Play Console: **Criteri per i contenuti > Classificazione dei contenuti**.
Categoria app suggerita: **Auto e veicoli** (Auto & Vehicles) — alternativa: **Strumenti** (Tools).

Con il supporto Android Auto introdotto nella versione 2.0, la categoria primaria **Auto e veicoli** risulta ancora più appropriata. Le risposte al questionario qui sotto sono state verificate contro il comportamento della 2.0 e restano invariate: le funzionalità Android Auto non introducono permessi nuovi, accesso a Internet, condivisione della posizione, contenuti generati dagli utenti né pubblicità.

## Risposte suggerite al questionario IARC

Tachimetro non contiene alcun contenuto generato dall'app stessa: nessuna violenza, nessun contenuto sessuale, nessuna sostanza controllata, nessun linguaggio volgare, nessun contenuto pauroso/horror, nessun gioco d'azzardo simulato.

| Domanda | Risposta |
|---|---|
| Violenza | Nessuna |
| Contenuti sessuali/nudità | Nessuno |
| Linguaggio volgare | Nessuno |
| Contenuti che incitano all'odio / discriminazione | Nessuno |
| Sostanze controllate (alcol, tabacco, droghe) | Nessun riferimento |
| Gioco d'azzardo simulato | No |
| Contenuti spaventosi/horror | No |
| Contenuti generati dagli utenti (UGC) | No — nessuna funzione social, chat, upload o condivisione |
| Condivisione della posizione con altri utenti | No — la posizione non viene mai condivisa, solo elaborata localmente |
| Interazione tra utenti (chat, community) | No |
| Acquisti in-app | No |
| Pubblicità | No — nessun SDK pubblicitario integrato |
| Accesso a Internet | No — l'app non dichiara il permesso INTERNET |

## Classificazione attesa

Con queste risposte, l'app dovrebbe ricevere la classificazione minima disponibile su tutti i sistemi IARC:
- **PEGI:** 3
- **ESRB:** Everyone
- **USK:** 0
- **Classificazione generale Google Play:** Tutti / Everyone

## Target audience e contenuti

- **Target audience:** non specificamente rivolta ai minori; adatta a un pubblico generico (conducenti di auto/moto).
- **App rivolta principalmente ai minori (Designed for Families)?** No — non è necessario aderire al programma Families.

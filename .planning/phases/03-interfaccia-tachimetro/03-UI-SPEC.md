## Layout Contract (Android-specific, replaces generic component inventory)

Single reused `TextView` (`messageText`, existing `id`, do not rename without updating `MainActivity.kt`) displays both the speed number and every status message, per CONTEXT.md D-03. One adaptive layout file — no `res/layout-land/` variant (D-02).

| Element | Requirement |
|---------|-------------|
| `messageText` width/height | Must be `0dp` (match-constraint) on **both** width and height, constrained to parent start/end with the horizontal margin below, so `autoSizeTextType="uniform"` has an actual bounding box to size against in both portrait and landscape. (Current XML uses `wrap_content`, which must change — autosize cannot grow/shrink against a self-sizing box.) |
| `messageText` alignment | `android:gravity="center"`, `textAlignment="center"` — number/message always centered (UI-01) |
| `messageText` autosize | `autoSizeTextType="uniform"` with explicit min/max/step (see Typography table below) — do not use the `autoSizePresetSizes` array form |
| `retryButton` position | Unchanged from current layout: below `messageText`, centered, vertical chain `packed` (D-04) — only re-centered as a side effect of `messageText`'s new bounding box |
| `retryButton` touch target | Minimum 48dp height (Android accessibility minimum — not the 44px iOS figure) |
| Max-speed area (Phase 4) | None reserved. No placeholder view, no extra constraint space (D-05) |
| Animations | None. No layout transitions, no `TransitionManager`, no property animators (UI-04) |
| Icons/graphics | None beyond the two text-bearing widgets already in the layout (UI-04) |

## Typography

Dynamic autosize replaces fixed size tiers for the dominant element. Two roles only — this phase has no body copy or headings (flat single-screen UI per UI-04).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Display (`messageText` — speed number AND status messages, same view) | `autoSizeTextType="uniform"`, `autoSizeMinTextSize="12sp"`, `autoSizeMaxTextSize="300sp"`, `autoSizeStepGranularity="4sp"`. Renders near the max end (~200–300sp) for 1–3 digit speed numbers; shrinks automatically to the low end (~12–24sp) for the longest status string ("Permesso GPS negato. Aprire le impostazioni per abilitarlo") — this is what produces the visual hierarchy per D-03, no second text element needed. | Black/900 via `android:textFontWeight="900"` (supported: minSdk 30 ≥ API 28) with `android:textStyle="bold"` as a belt-and-suspenders fallback attribute, `android:fontFamily="sans-serif"` (system default) | Not applicable — autosize governs box-fit; do not set a fixed `lineSpacingMultiplier`. Allow line wrap (do not force `singleLine`) so the longest permission-denied string can wrap to 2 lines rather than shrink to unreadable size. |
| Label (`retryButton` text: "Riprova" / "Apri impostazioni") | 16sp fixed — inherit the platform default `Widget.AppCompat.Button` text size, do NOT put this view inside the autosize scope | Regular (system default Button style — do not override) | 1.2 (platform default) |
| Body | Not applicable — no secondary body copy in this phase | — | — |
| Heading | Not applicable — no headings, flat single-element screen (UI-04) | — | — |

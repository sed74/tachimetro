## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Post-merge build/test gate non copre Gradle | Il gate generico di `execute-phase.md` (step 5.6) sniffa solo npm/cargo/go/python/make/Xcode — un progetto Gradle/Kotlin come questo non viene mai rilevato e il gate si auto-skippa silenziosamente | advisory | Eseguire manualmente `./gradlew.bat assembleDebug` e `./gradlew.bat test` dopo ogni merge di wave che tocchi codice, finche' `workflow.build_command`/`workflow.test_command` non vengono impostati in `.planning/config.json` |
| Perdita del SUMMARY.md da worktree | Un `gsd-executor` isolato lascia il suo `SUMMARY.md` **non committato** nella worktree (il docs commit spetta all'orchestratore). Fare `git worktree remove --force` senza prima copiarlo fuori lo distrugge: i file untracked non viaggiano nel merge | advisory | Prima di `git worktree remove`, sempre `cp` di ogni `*SUMMARY.md` dalla worktree al path corrispondente nel checkout principale. **Applicato correttamente il 2026-09-22** sulla quick task 260922-du0 — nessuna perdita |
| Heredoc bash che collassa i doppi backslash | Scrivendo `HANDOFF.json` via heredoc con delimitatore quotato, le sequenze `\\` sono state collassate a `\` singolo, producendo JSON non valido sui path Windows | advisory | Per i path Windows dentro JSON usare slash normali (`C:/Users/...`), oppure scrivere il file con lo strumento Write invece che via heredoc |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.

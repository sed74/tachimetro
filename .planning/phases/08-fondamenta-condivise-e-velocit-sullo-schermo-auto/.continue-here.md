- [ ] CONSTRAINT: sc1-panetemplate-non-soddisfa-core-value — `PaneTemplate`/`Row` (Car App Library, categoria POI, scelto a inizio milestone) non espone alcuna API per font size, allineamento o posizione del testo — il rendering è interamente host-controlled. Verificato dal vivo (screenshot utente su DHU reale): il numero appare piccolo, in alto a sinistra, con l'icona app anch'essa in alto a sinistra (obbligatoria: `PaneTemplate` richiede titolo testuale O header action, D-03 esclude il titolo testuale, quindi `Action.APP_ICON` resta l'unica opzione valida). Questo era un rischio accettato in astratto (D-01 di `08-CONTEXT.md`: "pur sapendo che lo stile è host-controlled") ma la sua manifestazione concreta è in tensione diretta con il Core Value della milestone v2.0 ("mantenendo il Core Value di leggibilità istantanea anche sul display del veicolo", PROJECT.md). **Non è un bug risolvibile con una modifica di codice minore.** — Mitigazione: NON tentare fix cosmetici sul `PaneTemplate` attuale (non esistono leve API per quello che l'utente chiede). Serve una decisione esplicita dell'utente tra: (a) accettare il layout host-controlled restando in categoria POI, (b) passare a `NavigationTemplate`+`SurfaceCallback` (disegno Canvas custom, controllo pieno) riaprendo la decisione di categoria NAVIGATION già "lockata" in PROJECT.md, (c) altra via. Probabilmente merita una sessione dedicata `/gsd:discuss-phase 8` data la portata (tocca Key Decisions già lockate).
- [ ] CONSTRAINT: sideload-non-funziona-su-head-unit-reale — Le app Car App Library NON possono essere testate via sideload (`adb install`) su un head unit Android Auto reale (auto vera): il toggle "Fonti sconosciute" di Android Auto esplicitamente non si applica a questa libreria (`.planning/research/STACK.md:122`). L'unico percorso di test pre-produzione è DHU (Desktop Head Unit, supporta sia AVD sia telefono fisico via USB) oppure Play Console Internal Test Track/Internal App Sharing. — Mitigazione: non proporre mai "collega il telefono alla tua auto vera" come test per questa fase; usare sempre DHU.

**Do not proceed until all boxes are checked.**
